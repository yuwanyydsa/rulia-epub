# EPUB 阅读插件

这是一个为 RuliaReader 开发的 EPUB 电子书阅读插件。

## 功能特性

- ✅ **EPUB 文件解析** - 支持标准 EPUB 2.0/3.0 格式
- ✅ **章节管理** - 自动识别和导航书籍章节
- ✅ **元数据提取** - 读取书名、作者、封面等信息
- ✅ **文本渲染** - 将 EPUB 内容渲染为可读的文本页面
- ✅ **书签记忆** - 记录上次阅读位置

## 使用方法

1. 将此插件安装到 Rulia
2. 在 Rulia 中导入 EPUB 文件
3. 开始阅读！
